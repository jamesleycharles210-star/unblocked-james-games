# Unblocked James Games

Portal estático de jogos HTML5 hospedados no próprio GitHub Pages. Os 27 jogos em `games/` foram obtidos do projeto [Arcadia](https://github.com/JeffreyHamilton6399/arcadia), de Jeffrey Hamilton, e distribuídos sob a licença MIT. O aviso original está em `ARCADIA-LICENSE.txt`.

Os jogos abrem dentro do portal por iframe local. Foram incluídos apenas os jogos hospedados no próprio projeto original, sem os jogos que redirecionavam para sites externos. A disponibilidade em redes escolares depende das regras da rede; este projeto não contorna filtros ou restrições.
